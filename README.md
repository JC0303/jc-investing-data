# jc-investing-data

Weekly snapshot of U.S. public-company quarterly revenue and net income from the SEC XBRL frames API, used by the "Claude invest" Google Sheet (`IMPORTDATA` on `data/sec_revenue.csv`).

- Source: https://data.sec.gov/api/xbrl/frames (public domain)
- Schedule: GitHub Actions, Monday 05:17 Asia/Taipei, plus manual runs
- Contact for SEC fair-access policy is stored in the `SEC_UA` repository secret
