## 後續測試

同一研究問題的選股、持有期、市場、事件間隔及主要結果選擇都要計入家族。對事前封閉的 N 個比較，雙尾 Bonferroni 要求 p ≤ 0.05/N，正向臨界 t 是 t 分布的 (1−0.05/(2N)) 分位數，自由度 G−1。仍需通過全部原門檻。相關變體同樣適用，但每個個別 p 值必須有效。只計勝出者會低估 N。

此登錄有 50 列歷史紀錄（含診斷與重算）。為容許持續新增，歷史家族保留 0.025，回顧比較保守地用 0.025/50。未來依序使用 new-1、new-2 等不重用的 ID。第 k 次新檢定雙尾額度為 0.025/[k(k+1)]，所有未來額度總和為 0.025。失敗或揭盲後不得回收額度。每個可以選為發現的主要結論占一個 ID。歷史未記錄的嘗試、事後形成的假設不因校正而具有驗證效力。

執行前新增六欄，填日期、可否證的主要假設、分割與所有門檻、結果 REGISTERED、單檔 Python 程式的 SHA-256。程式讀取工作目錄內三份帳本，輸出單一 JSON 物件，含雙尾 p、原門檻全部通過的布林值 gates_passed 及樣本結果。樣本不足用 null。程式與登錄一起提交。執行後把結果欄更新為數值、日期與執行連結，包含錯誤、樣本不足及失敗。保留原始假設、門檻與程式 hash。最終檢定另立 ID，並在看結果以前凍結。
